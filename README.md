# DecisionIQ

DecisionIQ is an AI Decision Intelligence Platform designed to help business owners and executives turn business data into actionable decisions.

## Core Workflow

Upload Business Data
→ AI Analysis
→ Executive Insights
→ Business Recommendations
→ AI Decision Assistant
→ External Market Intelligence

## Technology

- Native.builder
- React
- Supabase
- AI/ML API
- Bright Data

## AI Agents

- Data Analysis Agent
- Executive Advisor
- DecisionIQ Assistant
- Market Intelligence Agent
